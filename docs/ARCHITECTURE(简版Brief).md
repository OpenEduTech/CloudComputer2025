## 核心组件

### 1. 前端层 (Frontend)

**技术栈**:
- Vue 3 (Composition API)
- Element Plus (UI组件库)
- Pinia (状态管理)
- Axios (HTTP客户端)
- Vite (构建工具)

**职责**:
- 用户界面展示
- 用户交互处理
- API调用封装
- 状态管理

**容器化**:
- 多阶段构建：Node.js构建 + Nginx部署
- Nginx反向代理到后端
- 静态资源缓存优化

### 2. 后端层 (Backend)

**技术栈**:
- FastAPI (Web框架)
- Python 3.11
- Pydantic (数据验证)
- python-pptx, PyMuPDF, OCR (文档解析)
- OpenAI SDK (DeepSeek兼容调用)

**职责**:
- RESTful API服务
- 业务逻辑处理
- 文档解析
- Agent编排

**核心模块**:

#### 2.1 PPT解析模块
- 支持PPT/PPTX/PDF格式
- 提取标题、内容、图片、备注
- OCR提取图像文本
- 文档结构化存储

#### 2.2 知识扩充Agent
- LLM调用（DeepSeek）
- Chain of Thought推理
- 多维外部资源检索（Wikipedia, Arxiv, Semantic Scholar, OpenAlex, StackExchange, Bing/Google可选）
- 校验层防止幻觉

#### 2.3 出题Agent
- 动态题目生成
- 多种题型支持
- 难度梯度控制
- 题目质量校验

#### 2.4 判卷Agent
- 选择题自动判分
- 主观题LLM评分（Prometheus方法）
- Answer Embedding Similarity（答非所问检测）
- Chain-of-Thought对齐评分（摘要）
- 错误类型分类（概念错/计算错/理解偏差）

### 3. 数据层

#### 3.1 ChromaDB (向量数据库)
- **用途**: 语义检索
- **功能**:
  - PPT内容向量化
  - 相似度搜索
  - 上下文检索

#### 3.2 Redis (缓存)
- **用途**: 
  - 题目临时存储
  - 错题本持久化
  - 会话管理
- **特性**:
  - 键值存储
  - 过期时间管理
  - 集合操作

### 4. 外部服务

#### 4.1 DeepSeek API
- **Base URL**: https://api.deepseek.com
- **模型**: deepseek-chat / deepseek-reasoner / deepseek-embedding
- **用途**:
  - 知识扩充
  - 题目生成
  - 答案评估
- **容错**:
  - 重试机制
  - 超时控制
  - 降级策略

#### 4.2 外部知识库
- Wikipedia API
- Arxiv API
- Semantic Scholar API
- OpenAlex API
- StackExchange API
- Bing Search / Google CSE（可选）

## 数据流

### 1. PPT上传与解析流程
```
用户上传PPT → 文件校验 → 存储到本地 → PPT解析 → 图像OCR → 向量化索引 → 返回结果
```

### 2. 知识扩充流程
```
用户查询 → 向量检索上下文 →（可选本地预筛）→ 构建Prompt → LLM调用 → 响应解析 → 校验 →
外部资源检索 → 聚合结果 → 返回
```

### 3. 出题判卷流程
```
请求生成题目 → 向量检索定位知识点 → 约束上下文 → Agent生成题目 → 题目校验 → 缓存到Redis →
用户答题 → 提交答案 → 相似度检测 + LLM评分 → 错因分类 → 生成反馈 → 记录错题（如有）→ 返回结果
```

## 监控与日志

- **日志级别**: INFO, WARNING, ERROR

- **健康检查**: `/health` 端点
- **性能指标**: 请求时间、成功率
